# 07 / 发布验收清单

## 软件测试与真实部署测试分开

本包在隔离Linux运行环境执行的测试结果见 `reports/TEST_REPORT.md`。单元/API测试、DOM浏览器测试、模拟路径分析都不能证明真实微信网络、服务器证书、生产ACL或心理测量效度。没有执行的验收必须留空，不能替用户打勾。

## 发布阻断项

- [ ] 最终域名经用户批准，DNS仅新增本站记录，没有覆盖原站。
- [ ] 两端真实Tailscale地址已验证，应用端口未占用；源/目标/端口权限验证通过。
- [ ] 专用非root账户、UID/GID、独立本地磁盘目录、SELinux/ACL均获批准。
- [ ] Nginx配置只新增本站片段；`nginx -t`通过；TLS证书覆盖域名且续期已验证。
- [ ] `PUBLIC_URL`为最终HTTPS源地址，无localhost、100.x或内部IP。
- [ ] 数据负责人、联系方式、同意说明、实际学号格式、保留期限已确认。
- [ ] 备案/站点主体/活动采集权限已按真实情况核对，不捏造号段。
- [ ] 正式环境关闭ENABLE_DEMO；强口令已私密交付；secret未进入Git、聊天或web目录。
- [ ] `pytest -q`通过；目标Python/SQLite日志模式已记录。旧SQLite保持默认DELETE。
- [ ] 完成备份与隔离恢复演练，带最新删除清单；已撤回记录未复活。
- [ ] 对外展示文字不宣称已科学验证的人格分类，不自动录取/淘汰。

## 学生流程：真实设备检查

每条测试记录标注设备、系统、微信版本、网络、时间、截图编号和是否通过。只使用虚构或明确授权的测试学生，不混进正式名单。

| 步骤 | 期望 |
|---|---|
| 微信扫码 / 识别群内二维码 | 到最终HTTPS域名，不跳开发地址，无凭证出现在URL |
| 登记表空填、非法学号、未勾同意 | 明确阻止提交，不出现错误回显的个人信息 |
| 正常姓名/前导零学号 | 登记成功；拿到独立恢复码 |
| 重复学号 | 不覆盖，不仅凭姓名打开原记录 |
| 五条主路线各一次 | 命中对应N05、N14和春季3节点，单局32 |
| 返回N04改路线 | 后面旧答案截断，不混算两条路线 |
| 重载恢复 | 有凭证时恢复，无凭证无法按学号窥视 |
| 断网与恢复 | 已加载页面可继续，联网补存；没回执不显示完成 |
| 作品跳过/80字/排序 | 不扣资格，长度与顺序限制正确，无自动编造作品分 |
| 拒绝联系 | 仍可结算，不被记录为同意招募 |
| 最终提交、多次点击 | 同一回执，后台同一条记录 |
| 分享 | 不含姓名、学号、联系方式、恢复码 |
| 撤回删除 | 主库立即无该记录，恢复码失效，删除墓碑更新 |

Android微信+iOS微信各至少一次；校园Wi-Fi和手机流量各至少一次。现场设备无法测试时明确列为尚未通过，不给二维码正式发布许可。游戏页面首次加载需要网络；不是无网络可冷启动应用。

## 后台检查

未登录访问API返回401；错误密码及限流正常；cookie在HTTPS下Secure/HttpOnly；无CSRF写操作返回403；按完整学号精确查询正常；CSV的0开头学号、中文和公式注入防护正确；作品仅人工评阅覆盖岗位；补发恢复码使旧码失效；删除和导出有审计；退出后API不可访问。

后台允许公网访问还是管理IP白名单必须明确记录。白名单应测试真实管理网络的源IP，而不是把TailscaleIP填进去就以为从普通手机能登录。

## 负载与故障

从独立staging发起20/50等阶梯并发测试，记录p50/p95、错误率、CPU、内存、DB锁等待、网络RTT。包括注册、进度、提交和后台查询，不只GET首页。校园NAT可能让很多学生共享IP，检查限流不会误伤。

本包的本地小并发测试不等于正式“支持多少人”的承诺。SQLite单写者、校园链路、杭州带宽和主机当前科研任务都需现场评估。出现持续锁冲突时先减少无效写入与评估需求；更大规模需设计PostgreSQL迁移，而不是盲目堆Uvicorn worker。

人为停止本站应用后杭州应显示维护页；恢复后不能丢已确认提交。测试日志盘满、备份失败、网络暂断时，确认告警和人工恢复路径，不用真实数据做破坏性演练。

## 二维码验收

只在最终URL验证后生成。比对二维码实际解码URL与PUBLIC_URL完全一致，包含HTTPS且没有身份参数。手机扫打印件与屏幕图片各一次。二维码发布者只公开学生入口，不公开后台QR或管理员凭证。

验收完成后，agent填 `docs/09-agent-delivery-template.md`，连同经脱敏证据交给用户，保留未完成项。
