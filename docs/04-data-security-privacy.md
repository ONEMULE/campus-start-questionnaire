# 04 / 数据、身份、安全与隐私

## 目的与信息最小化

正式参与记录姓名、完整学号、届次、同意说明版本、原始作答、作品提案、结局和策略指示；用于本次活动登记、结果生成、经允许的体验联系。后续邀请选择和联系方式另行询问。不要求宿舍、家庭经济、身份证号、精确位置、心理疾病、政治宗教、恋爱或其他无关敏感资料。

姓名学号不是评分特征；MBTI只是娱乐字段；拒绝联络不影响完成，也不能由工作人员自动加入招募名单。公开结果文案不带姓名、学号、联系方式或恢复码。后台显示身份是工作需要，不代表可以转发截图或公开排名。

用户在登记前看到实际数据负责人、联系渠道、保留周期和撤回方式。负责人应审核活动信息采集的必要性与授权基础、学院名义使用、隐私说明及任何自动化推荐用途；本包中的技术控制不是法律合规认证。研究用途、论文发表、跨活动复用或向第三方提供信息不包含在当前同意中，须另行评估与授权。[官方依据见sources第5项。]

## 身份校验究竟做到哪里

学号是字符串，默认6–16位数字；这仅是可配置的语法校验，不是本校的真实学号规则承诺。Unicode全角规范化后保留前导零。姓名2–40字符，排除控制字符和危险分隔；特殊姓名需负责人协助处理，不给人贴假身份标签。

同届次+学号通过HMAC索引唯一约束防重复记录。重复登记不会覆盖旧记录，也不会仅凭姓名学号打开别人的答案。恢复需要高熵随机恢复码，遗失时由管理员核验后轮换，旧码随即失效。

可选授权名册只保存姓名HMAC和学号HMAC，用于字段匹配；知道他人姓名学号的人仍可能冒填。因此，**名册匹配不是本人认证**。正式评优、资格审查等高影响场景应接学校SSO等真实身份机制，本包没有伪称集成它。

## 数据表与加密

`participants`：opaque UUID、届次、学号HMAC、恢复码哈希、同意版本、状态、进度revision、时间、回执；identity、answers、result、review四类JSON字段使用Fernet认证加密。

`admin_sessions`：管理员会话token哈希、CSRF值、有效期。`rate_limits`：按加密索引密钥派生的来源键与时间计数，不直接保存IP。`audit`：操作者角色、动作、记录UUID与时间，不保存姓名学号或答案正文。`roster`：届次和HMAC字段，不保存明文名册。

这是**字段级加密**，不是SQLCipher全库加密。状态、时间、UUID等元数据仍明文。数据库、WAL/SHM（若启用）及备份必须权限隔离，主机丢失风险还需平台层磁盘加密与系统安全措施。

密钥分离：DATA_ENCRYPTION_KEY负责可解密字段，INDEX_HMAC_KEY负责唯一索引，EDGE_TOKEN用于两端入口，ADMIN_PASSWORD_HASH为scrypt哈希。密钥存在私有环境/秘密配置中，不发浏览器。不能同时把数据库和环境密钥提交到仓库；备份恢复既需要数据密钥，也需要同一HMAC密钥，升级不可自动轮换。

## 学生侧恢复与撤回

恢复码是访问凭证，拿到的人可读取或删除记录，应私下保存，不发群、不入URL、不放二维码。浏览器使用sessionStorage暂存本次凭证与作答，不持久保存姓名学号；联系方式在浏览器存档副本中去除，但自由文本可能包含用户自填的信息，不承诺对自由文本自动脱敏。

已加载页面可以暂时断网继续选择，联网后补存；离线刷新不能重新从网络加载页面，不是PWA离线应用。只有收到服务器提交成功及回执才算已完成。清除本机凭证只是退出，不删除服务器记录。

持有效恢复码可撤回删除活动库中的个人记录；后台也可核验后删除。删除动作留下最小UUID墓碑用于恢复重放。备份和已导出文件不能被浏览器立即物理删除，负责人需在声明周期内清理，恢复时必须应用最新删除清单。

## 管理员侧

单独管理员账号；随机初始强口令；scrypt口令哈希；HTTPS时Secure+HttpOnly+SameSite=Strict会话cookie；8小时会话；写操作校验CSRF；登录有数据库限流及边缘限流。未提供MFA和多人角色分权；多人管理需求应升级独立账号审计，不通过群内共享口令解决。

导出必须登录，CSV加入UTF-8 BOM；学号前缀文本标记保留零，文本字段防公式注入。CSV是明文导出，权限保护在下载后不会继续自动生效，禁止放公共网盘或分享链接。检索用完整学号精确匹配，不提供公开学生搜索。

## 网络与应用控制

严格请求模型拒绝额外字段；服务器重新计算分数；限制128KiB请求；校验源Origin及Host；相对同源API；生产入口校验edge token；CSRF写操作保护；动态内容HTML转义；CSP禁止外部脚本；安全响应头；不接入广告、分析SDK或第三方字体。

不把0.0.0.0监听、`forwarded-allow-ips=*` 或宽泛Tailscale授权当方便默认值。TLS终止在杭州，杭州到server为Tailscale加密链路内的HTTP。双机并不自动等于高可用；杭州管理员仍是受信任的数据通道管理者。

## 保留与事故处置

默认提交后90天、未完成登记起7天；定时任务每天清理，负责人应把清理频率与隐私文本中的期限对齐。滚动备份默认30天，删除墓碑至少覆盖备份窗口。名册有单独clear-roster流程；活动结束后另行清理，不因参与记录删光就误认为名册也已清理。

发现泄露或异常：先暂停本站入口/导出与未知会话，保留最小审计，核查范围，通知实际负责人并按要求处理。只轮换后台会话或口令不等于完成数据库密钥轮换；已有数据密钥迁移必须专门设计。没有证据不能在结果中宣称“零风险”“完全合规”或“绝对匿名”。
