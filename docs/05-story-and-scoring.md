# 05 / 剧情、规则与后续内容开发

## 题目口径

展开题库52节点；每位玩家32个剧情交互。另有一次入场登记表（姓名+学号+说明同意），不是心理题。N19可跳过，N28可跳过；G1–G8是后台快照，不额外要求8道回答。

```text
N00-N04
   ↓
N05-A/R/C/O/E 取一条（优先按N04第一兴趣）
   ↓
N06-N13
   ↓
N14-A/R/C/O/E 取一条（此前累计兴趣）
   ↓
N15-N19
   ↓
A01-A03 / R01-R03 / C01-C03 / O01-O03 / E01-E03
   ↓
N20-N28
   ↓
服务器校验、结算、固定回执、可选人工评阅
```

科研统一使用R，学业A，创作C，组织O，探索E。节点ID以 `content/questions.v1.json` 和 `reports/content-audit.json` 为准，不从历史Word的旧编号推导。

## 核心数据定义

每个节点有id、chapter、title、scene、prompt、type、options等字段。选项effects可以包含dims、interests/interest、flags、positions、meta。`multi`使用有序数组，第一偏好与第二偏好不同；`allocation`记录多选及costs；`worksample`为任务对象；`contact`只包含choice和可选contact；`mbti`为字符串或空串。

身份登记不放进QUESTIONS，不把姓名学号重复塞进每个答案。UI只负责展示和即时可选校验；服务器验证连续路径，客户端提交不含可被信任的总分。

## 路线与修改历史

N05采用N04的第一选择；N14采用N00+N04的累计兴趣；春季采用N00+N04+N18。平局按玩家最新有序选择优先，最后才使用固定路线顺序。N24只影响最终兴趣结果，不反过来改变已发生的春季。

返回前面修改时，客户端截断此节点之后的答案，再按新选择重新生成路线；服务器拒绝不属于新路线的旧答案。进度用递增revision避免晚到网络请求覆盖新状态。已正式提交后答案冻结；复盘变更规则需建立新版本或明确的重新参与流程，不从后台静默篡改。

## 15项策略指示，不是15项已验证人格

AI主动启动、PE持续执行、TR时间可靠、CO好奇开放、LA学习敏捷、FA反馈吸收、SS社交启动、CW合作意识、OC组织协调、AD适应变化、RR任务挫折后重启、UT不确定容忍、RA责任承担、PQ品质意识、CE创意探索。

这些是当前选项的设计标签。自报“我想剪辑”不能证明真正有后期能力；选择休息、礼貌拒绝或倾听不应被解释成能力不足。当前题库仍存在构念混合和路线机会不一致，只能作为待验证的情境设计。

对于每个指标：当前单选场景所有选项中的最大标记为分母，所选项标记为分子，累计比值R；出现该指标的已呈现场景数为n。

```text
R = 累计所选证据 / 累计该题最大可能证据
S = round_clip(50 + (100*R - 50) * n/(n+2), 0, 100)
```

n=0时S=50但显示“未观察”，不能当作中等能力。没有选择某项策略在这个算法中贡献0，意味着这一次选择了另一种做法，而非人格缺陷。`evidenceCounts`是相关场景呈现次数，不是有效信度或独立行为发生次数。`coverage`不称“高置信度”。

N10行动力多选不进入维度计分，不把6项任务当6次独立观察。超预算只记录OVERCOMMIT剧情标记。成长目标、自我认同、姓名学号、时间承诺、MBTI均不用于能力推断；时间只用于现实安排。

## 兴趣

兴趣来自N00、N04、N18、N24；沿用原题给出的有序权重。当前显示值以总上限8映射0–100，这是游戏刻度不是兴趣测量百分位。具体上限和单选/多选权重以JSON为准。

## 结局：修复“几乎人人得到同一结果”

历史Word把高分阈值与强迫取舍的题目搭配使用，却没有校准。软件随机路径探测（固定种子，3000条虚构路径，不代表新生人群）发现，原绝对条件使2999条都落入“起潮新芽”。因此本版不再把未达硬阈值等价于没有特色。

实现保留原组合条件作历史兼容候选；命中时使用对应剧情结局。没有命中时，以**兴趣路线+本局相对选择**进行娱乐叙事匹配：先对本局15个值去均值并除以20，再用各结局的叙事权重加上所属兴趣的1.25倍（兴趣除以100）。这不是人格常模、不改变15项数值、不进入录取决策。

“全栈潜水员”在前二兴趣差≤15、至少3条兴趣≥25、策略值标准差≤18时进入叙事候选。“起潮新芽”用于兴趣与策略均不鲜明，或最高两个叙事值差<0.06的情况。所有数字是**可版本化的游戏规则**，不是心理学分类阈值。第二候选是副标签，主页面显示结局依据。随机路径分布只用于检查软件退化，不能证明12类人格存在或每类应当占多少人。

## 体验岗位与作品

各岗位behaviorFit按代码ROLE_WEIGHTS归一。无人工作品时预览值：

```text
previewFit = (0.65*behaviorFit + 0.20*creativeInterest) / 0.85
```

人工作品评分为4项0–4，总和/16×100；只对该作品真正覆盖的岗位计入一次：

```text
reviewedFit = 0.65*behaviorFit + 0.20*creativeInterest + 0.15*sampleScore
```

写作提案覆盖编导策划或运营联络；剪辑排序提案只覆盖剪辑后期；照片选择覆盖摄影摄像的选片/观察线索。它们不等于真实相机操作、软件操作或成片能力。没有作品是“未提交”，不是0分；没有人工评阅时不能显示最终作品成绩。

## G1–G8

快照位置：G1=N03、G2=N05-*、G3=N09、G4=N13、G5=N16、G6=N19、G7=N23、G8=N28。每次只读取当时以前的答案；保存指标、场景数、flags、可靠性/恢复组合和路线提示。当前版本不依据这些门淘汰学生，也不实现旧Word中所有动态难度或NPC分支。

## 后续科学验证和内容质量

先做认知访谈、选项可理解性与社会赞许度检查；建立每条路线的覆盖矩阵；核实是否真的跨情境测同一行为。再在明确同意下，用真实作品及多人独立评分检验是否存在有用关联，分开报告样本量、不确定性与偏差。不能用本包的单元测试、随机模拟或漂亮雷达图替代心理测量验证。

当前上线用途宜为趣味体验、登记、方向推荐和邀请沟通。尚未验证的单一指标、内向标签、做题速度、设备和MBTI不得作为招募淘汰线。
